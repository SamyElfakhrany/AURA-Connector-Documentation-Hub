When to integrate

Capabilities are introduced when they create value in the employee journey, while AURA remains the experience and orchestration layer.

Stage 1

Pre-Join

Microsoft 365
  • Create guest or pre-hire identity
Saudi Connectors
  • Nafath identity check
  • Yaqeen data validation
AURA Integration
  • Identity verification flow
AURA Modules
  • Candidate Portal

Onboarding

Microsoft 365
  • Create Entra ID
  • Assign licenses
  • Set up Teams and Outlook
Saudi Connectors
  • Qiwa employment contract
  • GOSI registration
  • Mudad payroll setup
  • Muqeem for expatriates
AURA Integration
  • Orchestrate multi-system setup
  • Map employee data
AURA Modules
  • Onboarding Hub
Stage 3

Daily Work

Microsoft 365
  • Teams, Outlook and SharePoint
  • Planner, To Do and Viva
Saudi Connectors
  • Ongoing status checks
  • Expiry alerts and compliance updates
AURA Integration
  • Event synchronization
  • Real-time notifications
AURA Modules
  • My Day and My Focus
  • Projects
Stage 4

Employee Services

Microsoft 365
  • Document storage
  • Workflow notifications
Saudi Connectors
  • Absher government services
  • Ajeer temporary work
  • SADAD payments where applicable
AURA Integration
  • Integrate service requests
  • Retrieve documents
AURA Modules
  • Employee Services
  • Employment Profile
  • Expatriate Services
Stage 5

Move & Grow

Microsoft 365
  • Learning and collaboration
  • New-role access
Saudi Connectors
  • Contract updates through Qiwa
  • Role or permit changes through Muqeem
AURA Integration
  • Update employee profile and role
  • Approve and provision new access
AURA Modules
  • Learning & Growth
  • Manager Hub
  • Mobility & Travel

Exit / Rehire

Microsoft 365
  • Disable access
  • Archive data
  • Reactivate for rehire
Saudi Connectors
  • Contract termination through Qiwa
  • GOSI end of service
  • Final government clearances

  • Deprovisioning workflow
  • Data archival and rehire workflow
