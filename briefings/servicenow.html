01 · What is ServiceNow?

A cloud platform for enterprise service workflows

Verified

Platform

ServiceNow connects incidents, requests, approvals and fulfilment workflows on one enterprise platform.

Verified

APIs

The documented Table API performs controlled table operations; the Service Catalog API exposes catalog items and ordering actions.

Aura scope

Connector

A server-side Aura adapter that creates approved incidents or requests and returns ticket, approval and fulfilment status.

Simple distinction An incident reports something broken or disrupted. A service request asks for a predefined item or service. Status tracking shows progress, approval and the final outcome.

04 · How to integrate

A controlled employee-service journey

Aura employee

Incident / request
Status / approval
Aura update

Proposed architecture. The user reviews the form before submission. Credentials stay in the Aura backend; Aura maps only allow-listed fields and stores the ServiceNow record ID for status tracking.

Implementation plan that enables the journey above

Confirm instance and scope

Secure a customer non-production instance; select one incident journey, approved catalog items, an owner and the permitted status model.

Configure OAuth and ACLs

Create an external OAuth client and integration identity; grant only the table, catalog and field rights required for the pilot.

Build and map

Map Aura users, request fields and correlation IDs to the approved incident fields or catalog variables; return number, state and approval status.

Operate safely

Prevent duplicates, protect secrets, audit access and monitor failures. Respect Retry-After for HTTP 429 and back off temporary 5xx errors.

Initial scope only Create incidents, order a small approved catalog set and read status/approval. Exclude arbitrary table access, record deletion, privileged changes, unrestricted catalog access and attachments until explicitly approved.

Verified

OAuth client

ServiceNow documents creating an OAuth API endpoint for external clients in the Application Registry; an administrator configures it.

Verified

Rate limits

Inbound REST limits are instance-configured. A limit breach returns HTTP 429 and Retry-After; no universal public quota was verified.

Confirm with customer

Exact permissions

Allowed tables, catalog items, variables, approval transitions, status fields and notification method remain customer decisions.

Testing constraint ServiceNow offers a free Personal Developer Instance for generic API prototyping, but it does not contain the customer’s catalog, ACLs, workflows or data. Pilot UAT therefore requires the customer’s non-production instance.

Aura internal cost

Plan separately

Adapter development, catalog and field mapping, employee UX, QA, security/privacy review, monitoring and support.

How the company gets the real cost Check the existing ServiceNow contract → confirm ITSM/Service Catalog and API entitlements → request any license, add-on or non-production uplift → estimate implementation person-weeks using the company’s blended rate → add monthly infrastructure and support. Total cost = ServiceNow contract uplift + partner/add-on fees + implementation person-weeks × blended rate + Aura hosting/monitoring + support hours × support rate.
