01 · What is it?

Business apps + a shared data platform

Microsoft product

Dynamics 365

A family of business applications, including sales, customer service, finance and operations. The exact app determines the connector scope. [6]

Microsoft platform

Dataverse

Stores business data in tables and supports business logic. Its Web API lets Aura read or update permitted records. [1][6]

Aura scope

The connector

An Aura backend adapter for selected cases or custom request tables in the customer’s Dataverse environment.

Scope mattersDataverse is the starting route for this request/case pilot. Finance and Operations also exposes its own OData interface; ERP journeys require a separate API and module assessment. [8]

04 · How to integrate

Configure once, then run secure request journeys

A · Setup & onboarding

Select scope

Customer sandbox, exact app/table and one employee journey.

Grant access

Entra app registration + Dataverse application user + limited security role. [2][3]

Map & protect

Map employee identity, permitted fields and statuses; validate each user’s record access.

Test & release

Verify employee isolation, workflow behavior, retries and license coverage.

Setup enables the runtime flow below. Both belong to the same connector.

Entra issues the API token; it is not a separate data pipeline. With application access, Dataverse applies the app’s roles: Aura must also enforce employee-level access. Delegated access is an alternative when operations should use the signed-in user’s permissions. [2][3]

Endpoint pattern: https://<environment>/api/data/v9.2/. Discover actual entity sets and custom fields from tenant metadata. Keep credentials on the server; isolate tenants; audit actor and record ID; prevent duplicate writes; handle pagination and HTTP 429 using Retry-After. [2][5]

06 · Cost

No single fixed “Aura connector fee”

Budget for the customer’s product/access licenses, Aura implementation, hosting/support and any extra capacity or automation. Existing entitlements may cover some costs; confirm the incremental amount.

Paid yearly. Official US prices checked 01 Oct 2026; these are application-license examples, not API fees or a Saudi quote. Local currency, regional terms, tax and negotiated pricing require a Microsoft/CSP quotation. [10]

Employee access is the key pricing questionAn unlicensed application user is supported, but its technical access does not remove employee licensing obligations. Confirm rights per table, operation and access model; a shared backend identity is not a license exemption. [3][6]
Total = incremental licenses + one-time build + recurring hosting/support + required add-ons

Illustration: 10 Professional users × US$50 = US$500/month (US$6,000/year). This covers only those 10 application licenses; it excludes wider employee access, implementation and operations.

To get the company’s actual cost: send Microsoft/CSP the selected app and tables, read/write journeys, service-agent and employee counts, current licenses and expected API/storage volume. Request a Saudi commercial quote; obtain a separate Aura delivery estimate.
