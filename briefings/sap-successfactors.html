01 · What is SuccessFactors?

SAP’s cloud human capital management suite

Verified

Platform

SAP SuccessFactors HCM is a cloud suite for core HR, payroll, recruiting, talent, learning and workforce processes.

Verified

API

The documented OData V2 APIs expose user, person, employment, job, foundation and other tenant-enabled HR entities.

Aura scope

Connector

A server-side Aura adapter that retrieves only approved HR fields from the customer’s SuccessFactors tenant for employee self-service.

Simple distinction User and person data identifies the employee. Employment and job data describes the assignment, company, manager and role. EmployeeTime covers absences and time off where the customer has enabled the relevant module.

04 · How to integrate

A controlled, read-only employee journey

Aura user
Aura backend
SAP OData
Approved HR fields
Aura display
Audit & monitor

Proposed architecture. Credentials and certificate keys stay in the Aura backend. Aura requests only allow-listed fields and applies the customer’s employee-access rules before display.

Implementation plan that enables the journey above

Confirm tenant scope

Confirm licensed modules, a test or preview tenant, employee journeys, HR data owner and approved fields.

Configure access

Register an OAuth2 client, configure the required certificate method and grant least-privilege API and role-based permissions.

Build and map

Map Aura employee IDs to User, PerPerson, EmpEmployment and EmpJob; add EmployeeTime only if licensed.

Operate safely

Use field allow-lists, secrets management, pagination, audit logs, monitoring and backoff for temporary or throttling responses.

Initial scope only Read employee profile, employment and job information. Add leave status only after module and permission confirmation. Exclude profile edits, employee creation, leave submission and approvals from the first pilot.

06 · Cost

Provider quotation required

SAP subscription

Price on request

SAP lists HCM Base and Premium as price upon request, in blocks of one user, with 1–5 year contracts and auto-renewal.

Confirm the customer’s existing contract first.

API and test access

Confirm

No separate public per-call price or standard public integration-sandbox price was verified.

Ask SAP or the implementation partner about API entitlement, modules, quotas and non-production tenant cost.

Aura internal cost

Plan separately

Adapter development, field mapping, employee UX, QA, security/privacy review, monitoring, certificate rotation and support.

How the company gets the real cost Check the existing SuccessFactors contract → confirm modules and API rights → request any license or test-tenant uplift → estimate internal person-weeks using the company’s blended rate → add monthly infrastructure and support. Total monthly cost = SAP contract uplift + optional partner/middleware fees + Aura hosting/monitoring + support hours × support rate.

Board decision requested

Approve a Wave 1 read-only pilot for employee profile, employment and job information; include leave status only if the Time module and required permissions are available.

Production gate: customer test tenant, signed field map, OAuth2/certificate setup, least-privilege roles, privacy approval, support model and written commercial confirmation.

Suggested owners: Aura Product and HR define journeys; the SAP tenant administrator and Security configure access; Integration Engineering builds the adapter; Privacy approves fields; Procurement or the SAP account owner confirms cost.
