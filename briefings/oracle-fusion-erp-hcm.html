01 · What is Oracle Fusion?

Cloud applications for people and business operations

Verified

HCM

Oracle Fusion Cloud HCM connects HR processes and employee information, including workers, assignments and absence management.

Verified

ERP / Procurement

Oracle Fusion Cloud ERP covers enterprise operations. The documented Procurement REST API can manage purchase requisitions and their approval lifecycle.

Aura scope

Connector

A server-side Aura adapter that retrieves approved HCM fields and selected requisition status; controlled write operations can be added later.

Simple distinction HCM lookup reads worker or leave information. ERP workflow creates or tracks a business transaction such as a purchase requisition. Approval status shows where that transaction is in the customer’s configured process.

04 · How to integrate

A controlled, customer-specific integration

Aura employee
Aura backend
Oracle Fusion REST
HCM / requisition result
Employee review
Aura update

Proposed architecture. Credentials and tokens stay in the Aura backend. Aura requests allow-listed fields only, enforces the customer’s access rules and stores Oracle identifiers only where needed for correlation.

Implementation plan that enables the journey above

Confirm modules and scope

Confirm HCM, Absence and Procurement entitlements; select one HCM read journey and one requisition-status journey with named data owners.

Configure OAuth and roles

Create a confidential application in the Fusion IAM identity domain; select the approved OAuth flow, scopes and least-privilege Fusion roles.

Build and map

Map Aura identity to PersonId/PersonNumber and assignment; map requisition header ID, number, document status and approved employee-facing fields.

Operate safely

Use field allow-lists, pagination, audit logs and monitoring. Retry safe reads after temporary failures; do not blindly retry write operations that could create duplicates.

Initial scope only Start with read-only worker, assignment, absence and requisition status. Add requisition creation and submission only after the customer signs off the payload, approval behavior, security roles and duplicate-prevention method. Exclude employee-data updates and broad administrative actions.

06 · Cost

Contract-specific

Oracle publishes a global price list with product SKUs, metrics and minimums, but the connector total depends on the customer’s HCM, Absence and Procurement entitlements.

Confirm the customer’s existing contract first.

Environment and integration

Confirm

One test environment is allotted with the subscription; extra development environments must be ordered. No separate standard per-call Fusion REST price was verified.

Confirm any Oracle Integration Cloud, additional environment, implementation-partner and data-egress cost.

Aura internal cost

Plan separately

Adapter development, HR/procurement mapping, employee UX, QA, security/privacy review, monitoring, quarterly-update regression testing and support.

How the company gets the real cost Check the existing Oracle order documents → confirm HCM, Absence, Procurement and REST access → identify additional environment, Oracle Integration Cloud or partner needs → estimate implementation person-weeks using the company’s blended rate → add monthly infrastructure and support. Total cost = Oracle license uplift + extra environment/OIC/partner fees + implementation person-weeks × blended rate + Aura hosting/monitoring + support hours × support rate.

Board decision requested

Approve discovery and a Wave 2 read-only pilot for worker/assignment data, optional leave status and purchase-requisition tracking. Keep requisition creation outside the first release.

Production gate: customer test environment, confirmed licensed modules, signed field map, approved OAuth flow, least-privilege roles, data-security testing, status/approval mapping, operational limits and written commercial confirmation.

Suggested owners: Aura Product, HR and Procurement define journeys; the Oracle Fusion administrator and Security configure IAM, roles and test access; Integration Engineering builds the adapter; Privacy approves employee fields; Procurement or the Oracle account owner confirms cost.
