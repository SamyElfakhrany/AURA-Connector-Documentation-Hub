01 · What is it?

A secure document-retrieval route for a specialized handover process

Official company

Kidana

Kidana Development Company is the Royal Commission for Makkah City and Holy Sites’ executive arm for developing, operating and managing the Holy Sites. [1] [2]

Gateway contract

Handover file

The supplied guide defines one GET operation that accepts reportId and returns a binary file using an owner-defined Authorization value. [4]

Aura scope

Authorized delivery

A server-side adapter that verifies the user/report relationship, retrieves the file, validates its type and size, and streams or stores it under policy.

Scope boundaryThe contract does not define report search, listing, metadata, creation, workflow, approval, project data or asset management. A report ID must come from an approved local business process, not from enumeration or user guesswork.
02 · Value for Aura

Deliver the right operational file to the right authorized user

Best fit: Kidana-facing Hajj operations, facilities, contractor or handover teams that already know the report identifier and need a controlled retrieval channel. The benefit is focused and seasonal rather than enterprise-wide.

04 · How to integrate

Authorize first, then validate every byte

Define the report

Name the handover process, report types, identifier source, classification, business owner and authorized roles.

Obtain access

Receive approved URLs, exact Authorization scheme/value lifecycle, allowlisting and test report IDs.

Validate delivery

Test success, missing report, permission failure, error JSON, empty body, wrong media type and oversized file.

Release with policy

Apply audit, malware scanning where required, retention, secure storage/streaming, expiry and support procedures.

06 · Access, prerequisites & blockers

Not build-ready until document ownership and access policy are explicit

Confirm before build

Prerequisites

  • Named Kidana/customer owner, eligible tenant, purpose and production entitlement.
  • Report taxonomy, classification, contents, lifecycle and authorized audience.
  • Trusted source of reportId and user-to-report authorization rule.
  • Sandbox/production URLs, exact auth scheme, credential rotation and network controls.
  • Approved MIME types, maximum size, filename/disposition behavior and error formats.
  • Retention, storage region, download expiry, support, SLA and commercial terms.
Delivery controls

Guardrails

  • Never accept an arbitrary report ID without local case and role authorization.
  • Vault provider credentials and prevent browser/direct upstream access.
  • Stream with strict byte limits; validate type, content signature and error payloads.
  • Sanitize filenames; force safe download behavior and malware scan if required.
  • Encrypt stored copies, prohibit public links and delete on the approved schedule.
  • Audit actor, purpose, case/report ID, type, size, result and delivery timestamp.

07 · Cost

No verified public endpoint price

The technical adapter is small, but total cost depends on partner onboarding, secure file delivery, malware/content controls, storage and retention, monitoring, user authorization and operational support.

Provider access

Environment provisioning, credential management, network route, transaction/usage terms and SLA.

Document security

Classification, scanning, encryption, storage, download expiry, audit and deletion controls.

Aura delivery

Discovery, adapter, case authorization, file validation, tests, monitoring and support.

Total = Kidana access/onboarding + Aura adapter and authorization + secure file controls/storage + recurring monitoring and support
Quote requiredRequest written terms from the confirmed integration owner for report types, users, expected size/volume, environments, authentication, data handling, SLA and support. A one-route contract does not mean zero onboarding or governance cost.

Board decision

Fund discovery only. Approve a read-only sandbox proof after report ownership, user authorization, exact credential scheme, file allowlist, storage/retention and support are confirmed. Do not position this as a broad Kidana operations connector.
